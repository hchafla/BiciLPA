# 🚲 BiciLPA

**BiciLPA** es un mapa ciclista de **Las Palmas de Gran Canaria** que reúne en un solo lugar la infraestructura ciclista, las rutas recomendadas, la normativa y los principales servicios para desplazarse en bicicleta o patinete eléctrico (VMP).

## Funcionalidades

### 🗺️ Mapa en Vivo
- Red de carriles bici, ciclocalles y vías ciclistas de Las Palmas de Gran Canaria.
- Estado en tiempo real de todas las estaciones **Sítycleta**.
- Disponibilidad de bicicletas eléctricas **eSítycleta** en tiempo real.
- Localización de talleres y otros puntos de interés para ciclistas.

### 🚴 Rutas Recomendadas
- Rutas diseñadas para moverse por la ciudad.
- Información sobre distancia, tiempo, desnivel y dificultad.
- Consejos prácticos para cada recorrido.

### 📖 Normativa
- Resumen claro de la normativa para bicicletas y patinetes eléctricos (VMP).
- Dónde se puede circular.
- Uso del casco, estacionamiento y equipamiento obligatorio.
- Principales multas e infracciones.

### 🔧 Talleres
- Directorio de talleres especializados en bicicletas.
- Información de contacto y ubicación.

## Objetivo

Facilitar la movilidad sostenible en **Las Palmas de Gran Canaria**, ofreciendo una herramienta gratuita con información útil y actualizada para residentes, estudiantes, trabajadores y visitantes que se desplazan en bicicleta o patinete eléctrico.

## Tecnologías

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- APIs públicas de Sítycleta y eSítycleta
